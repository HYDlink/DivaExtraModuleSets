DivaExtraModuleSets — Outfit Slot Expander Mod (v0.1.0)
==========================================================

Features:
1. Expands both native Shared Sets (A-Z, up to 26 slots) and Song Specific sets (1-10, up to 10 slots).
2. Press F4 in either Song Select or Customization to cycle through all configured slots (Shift+F4 cycles backward).
3. Press F8 (configurable in settings.ini) to open the in-game Settings & Slot Manager:
   - Toggle the extension on/off at any time (falls back cleanly to vanilla A/B/C + Song Specific while keeping all saved data intact).
   - Adjust visible Shared Set count (1-26) and Song Specific count (1-10) live.
   - Lowering slot counts ONLY hides higher-numbered slots from UI/cycling without deleting or truncating their saved data; increasing the counts again restores access to all previously saved outfits.
   - Quick-jump directly to any slot, adjust HUD badge visibility/offset/scale, or trigger an immediate save.
4. Save Data & Steam Cloud:
   - Stored in DivaExtraModuleSets.dat inside the game's Steam save directory (%APPDATA%\SEGA\Project DIVA MEGA39's\Steam\<SteamID>\), so Steam Cloud syncs it alongside your vanilla .dat save files without altering vanilla save format.
